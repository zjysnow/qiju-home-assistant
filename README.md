# 栖居家庭助手

可在电脑本机运行、用手机浏览器访问，并逐步接入本地 AI 和 Home Assistant 的家庭控制实验项目。默认只运行模拟设备；真实设备令牌只保存在服务端 `.env` 中，不会发送到浏览器。

## 1. 本机启动（模拟设备）

需要 Node.js 20.18 或更新版本。在项目目录运行：

```bash
npm install
npm start
```

运行后打开 <http://127.0.0.1:3000>。不需要数据库或额外本地服务；页面、角色素材及可选 Live2D 依赖均由本机提供，运行期间不访问第三方 CDN。首次 `npm install` 需要联网安装锁定版本的依赖。设备配置和模拟状态会保存在被 Git 忽略的 `data/devices.json` 中，重启服务后仍会保留。

如果页面提示 `Forbidden`、`Unexpected token` 或“本机服务未连接”，通常是通过 VS Code 静态预览或直接打开 `index.html` 了。请在项目根目录运行 `npm start`，再访问上面的地址；前端必须由 Node 服务提供，才能调用 `/api`。

首次启动时会初始化 `admin` 管理员账号：若设置了 `ADMIN_PASSWORD`（或旧配置 `APP_PASSWORD`），它会作为初始密码；否则本机启动会在终端生成并显示一次随机密码。管理员首次登录后，可在“家庭成员”中为每位成员创建独立登录名和密码。

登录时可选择“在此终端保持登录 30 天”。本机回环地址上的桌面浏览器默认勾选，首次用管理员密码登录后，服务重启也会自动恢复管理员会话；手机或其他网络地址不会默认勾选，家庭成员可按需信任自己的手机。管理员电脑和家庭成员手机分别关联到各自账号后，管理员可在“偏好”中的“已关联终端”查看并撤销任意家庭账号的终端。不要在公用设备上启用此选项；撤销或退出登录会移除该终端的持久会话。账号密码哈希和终端令牌哈希保存在 Git 忽略的 `data/users.json`。不勾选时仍使用 12 小时、服务重启后失效的临时会话。

忘记管理员密码时，先在运行服务的终端按 `Ctrl+C` 停止服务，再在项目目录执行：

```bash
npm run reset-admin-password
```

默认按提示输入并确认自选密码，输入过程不会回显。若希望命令直接生成安全随机密码并在终端显示一次，执行：

```bash
npm run reset-admin-password -- --generate
```

两种方式都只更新管理员密码哈希并撤销该管理员账号的已记住终端，不会删除家庭成员账号、个人偏好或设备数据。完成后重新运行 `npm start` 并使用 `admin` 和新密码登录。请勿在服务运行时执行重置命令，也不要通过删除 `data/users.json` 来找回密码。

常用测试指令：

- `打开客厅的灯`
- `关闭卧室空调`
- `开启观影模式`
- `打开所有灯`

未安装 Ollama 时使用内置的基础指令解析器；它不调用云端 AI。
连接 Ollama 后，底部“小栖”面板支持连续中文聊天和设备控制；服务端会恢复当前账号最近 200 条聊天记录，并将最近几轮对话作为上下文。设备操作仍只允许映射目录内的设备和场景。

每个登录账号可在“偏好”中设置默认灯光亮度和空调温度。登录不会自动改变设备；用户明确打开灯光或空调时，未指定亮度/温度的设备操作才采用该账号的偏好。成员账号不能管理设备或成员档案，管理员负责这些配置。

默认虚拟角色为**守岸人 · 无表情体验版**，登录或恢复登录时自动加载本机 Live2D 素材，并使用对应蝶影投影。原创小栖因美术与动作效果尚未达到正式角色标准，保留为实验性备选，不再作为默认形象。它采用雾银长发、折翼发夹、白色短外套和燕尾衣摆，是分层 SVG/CSS 而非 Live2D，无需运行库；桌面为 `176×220`，手机为 `144×180`。经典奶白小猫和 BongoCat standard 也保留在“选择模型”中，选择后点击“启用所选形象”。“原创小栖（实验）”按钮可直接切换到实验形象；已有上传皮肤不会被删除。

原创静态立绘稿可通过角色面板的“查看原创小栖的新静态立绘”或 `/qiju-design.html` 打开。第十一稿重画袖口到小手的衔接：去掉深蓝粗横带，改为浅色薄布边；露出一小段手腕，手腕与手掌共用连续轮廓，用轻微拇指转折区分小手与圆头袖端，不画密集分指。双臂保持收近身体的姿态，衣身与袖子仍共用完整外轮廓。保留垂近裙摆的长发、平整浅青胸前、窄圆领和小光燕挂坠；圆头、头巾、钟形裙摆及短腿保持不变。实测约 2.00 头身；测量头长时从主发顶到下巴，不计头巾、呆毛、长发和飘带。保留“归巢”飞燕发饰、燕尾飘带和裙面刺绣。仅参考 DeepSeek 娘的比例与姿态节奏，不使用参考角色图片或服装素材。衣装参考守岸人的轻盈层次，不直接使用或描摹模型贴图；不通过动画掩盖静态造型。透明背景原稿在 `assets/pet/qiju-portrait.svg`，独立预览页同时提供大图与 128 像素缩小图；不含动画，不读取家庭数据，也不替换默认守岸人或旧实验角色。此稿是手工矢量绘制，不是 Live2D 或生成式绘画成品。

**BongoCat / 守岸人 Live2D 模型**：守岸人在登录时自动加载，标准 BongoCat 可手动选择。点击角色打开面板，可查看许可、改变水印设置和切换角色。这里加载的是真实的 `cat.model3.json`、MOC3、纹理和物理资源，与原创 SVG 角色是独立的渲染路径。按此前本机用户的明确设置，运行库许可与隐藏守岸人水印默认勾选；可随时取消，小栖和经典小猫不受运行库许可限制。

- **守岸人 · 无表情体验版**：使用用户提供的“守岸人-无表情版”中 `A-守岸人/img/standard/cat_model` 资源，作者为**宇痕冫**。原说明仅允许个人使用和非盈利直播，禁止二次售卖。素材及作者说明原样保存在 `data/pet-models/shorekeeper/`，该目录已被 Git 忽略，不随项目源码分发；水印通过作者原生开关控制，不修改素材，也未尝试解锁体验版中没有提供的表情。已接入键鼠动作、视线、呼吸和语音口型；外围互动沿用现有 CSS 特效。本机已放好素材；在其他机器上需要自行取得授权素材并安装：

  ```sh
  mkdir -p data/pet-models/shorekeeper
  cp -R "$HOME/Downloads/守岸人-无表情版/A-守岸人/img/standard/cat_model/." data/pet-models/shorekeeper/
  cp "$HOME/Downloads/守岸人-无表情版/README.txt" data/pet-models/shorekeeper/LICENSE.txt
  ```

- **BongoCat standard**：素材来自 [BongoCat](https://github.com/vladelaina/BongoCat) 的内置模型，固定于提交 `29ccda67802e6b6727acae0bdf42f50277f9aade`；这些素材具有独立的 [MIT 授权](assets/bongocat/LICENSE-MIT.txt)，不包含其 AGPL 桌面程序源码。来源和许可见 [NOTICE](assets/bongocat/NOTICE.txt)。图库中的其他免费模型仍需逐个检查作者授权，“免费下载”不代表可任意再分发。

Live2D 使用本地 PixiJS 6.5.10、pixi-live2d-display 0.4.0 和官方可再分发 Cubism Core，**运行库许可独立于各模型授权**，见 [Live2D 许可](assets/bongocat/LIVE2D-LICENSE.html)。商业发布、可扩展模型平台等用途需另行核实 Live2D 的许可条件；当前仅接入上述两份固定模型，不支持任意模型包导入。`gh-pages` 是上游包误带的文档发布依赖，通过 npm override 固定到修复已知漏洞的 5.0.0，不参与浏览器运行。Pixi 使用 CSP 兼容适配，不允许 JavaScript `unsafe-eval`；只放开本地 WebAssembly 编译所需的 `wasm-unsafe-eval`。

守岸人原包提供 `syxs.motion3.json` 水印开关，对应 `Paramshuiying` 参数。网页的“隐藏守岸人画面水印”开关按本机用户要求默认勾选，使用该原生参数，不改动素材文件，也不移除面板作者署名。取消勾选可恢复水印。不会监听系统级快捷键或其他全局键盘事件。

守岸人体验版在 `ParamBreath > 0.5` 时会隐藏头和身体，不能直接使用标准猫的呼吸范围。该模型单独使用 `0.05–0.45` 的连续呼吸，减少动态效果时固定为 `0.25`；标准 BongoCat 的参数不变。

会话内可以切换模型、恢复水印或撤回运行库许可；退出登录会销毁模型并清除活动勾选状态，下次登录重新加载守岸人，并恢复此前授权的运行库与水印勾选设置。加载失败或 WebGL 上下文丢失会明确提示并回退到实验性小栖，不会把回退当成加载成功。

BongoCat 按模型实际参数响应输入敲键、指针转头、挥爪、眨眼和状态表情，外围跳跃、伸缩和粒子仍由 CSS 提供；不保证模型具备原创 SVG 的所有局部姿势。Live2D 仅在本体可见时以最高 30 FPS 渲染，后台、投影离开后暂停；减少动态效果时只按状态绘制静态帧。切回原角色或退出登录会销毁 WebGL 资源，撤回许可或切换过程中也不会留下过期加载结果。不会监听系统级键盘或上传输入、指针轨迹。

主角色平时固定在页面右下角。以下局部动作描述针对实验性 SVG 小栖，守岸人由其 Live2D 模型驱动：小栖轻微呼吸、眨眼，发束和燕尾衣摆缓慢摆动；经典小猫保留摆尾。聊天输入时双手小幅交替动作，出现半透明的小控制台；停止输入 550 毫秒或失去焦点后收手，不会因输入框里留有文字而一直敲击。点击角色会挥手，语音聆听时侧头、发夹信号点亮起，AI 请求期间托腮思考，实际语音播报期间才开合嘴巴。聊天请求失败会保留错误提示，并切换为认真表情，不用开心动作掩盖失败；新的请求、点击反馈或注销会清除此状态。动作按“聆听 → 思考 → 播报 → 错误 → 点击反馈 → 输入 → 投影待机 → 互动／自主动作 → 普通待机”的优先级互斥显示。指针轻微影响眼睛和头部位置；不会读取全局键盘，也不会记录或上传指针轨迹。

动作设计还参考了 [OpenPets](https://github.com/OpenPetsHQ/openpets) 的自主待机、互动反应和状态驱动思路，未引入其运行时、代码或素材。小栖在无操作约 **6–9 秒**后会随机伸懒腰、整理头发或打盹；经典小猫的整理动作仍为洗脸。相邻动作不重复，用户操作会唤醒角色，20 秒的电子幽灵出游时间不变。关闭投影仍保留这些原地待机行为。快捷面板中的“陪小栖玩”支持**摸摸头、喂零食、跳一跳、跳支舞**，仅为角色互动，不调用设备、AI 或语音服务，也没有需要照料的饥饿值或付费机制。主动互动会收起面板并通过状态区反馈，可连续选择动作，旧动作的结束计时不会打断新动作。

动画增加了跳跃前蓄力压缩、腾空拉伸、落地回弹和冲击圈，配合分批散开的星光、爱心、音符、语音波纹、思考光环，以及投影切换的全息光柱和传送环，全部用本地 SVG/CSS 分层绘制，无需 WebGL、音效下载或额外依赖。自定义图片皮肤保留整体伸缩、跳跃、摇摆和外围特效，但静态图片无法像默认 SVG 一样单独控制五官或手臂。工作状态仍优先于玩耍，输入、语音开始和 AI 请求会结束当前动作；面板、弹窗、录音、后台标签页期间不启动自主行为。退出登录会清理全部动作计时器。系统“减少动态效果”会关闭自主动作、投影和粒子特效，手动互动仍提供静态姿势与文字反馈。

页面连续 **20 秒没有操作**后，小栖通过扫描、微光解构与重组特效化为“**小栖 · 光燕**”：尖长掠翼、纤细燕身与分叉尾羽，青蓝和雾白配色呼应人形发夹及衣摆。光燕有正面、斜侧面、侧面三套翼型，约每 **0.32 秒**振翼一次；方向、倾斜、侧身与短光迹均跟随真实飞行切线，而非固定图案平移。选择并启用守岸人时才切换为原有“守岸人 · 蝶影”，保留其三视角构型与 **0.42 秒**翼拍；离开该模型会恢复光燕，未启用的下拉选项不改变当前投影。两种形态共享 `80×96` 视图和 `96×112` 不可交互外框，不持续渲染 Live2D。飞行由 `requestAnimationFrame` 驱动连续曲线，按路径长度设定每段 **0.9–6.5 秒**，以约 **100 像素/秒**为参考速度；完整曲线控制包络限制在可视区并避开右下角入口。两端共用约 **640 毫秒**的切换时钟，完成后右下角角色及名字牌完全隐藏，不保留透明点击区域或键盘焦点。系统“减少动态效果”会关闭投影、振翼、尾羽和光迹；用户操作、后台、缩放或退出登录会取消飞行帧。投影不接收点击、不抢焦点，也不执行设备指令。两种形态均为独立 SVG/CSS，未裁切或打包参考截图。

移动指针、点击/触摸、键盘输入或滚动会立即停止出游。光燕转向右下角，在约 **640 毫秒**内掠回并消散，同步展开成人形；守岸人的蝶影保持原有的原地消散与重组。回归开始时就恢复右下角的交互，不需要等动画结束，再重新等待 20 秒；持续移动鼠标不会反复重播回归，入场被打断或快速重复预览也不会留下过期计时器。打开快捷面板、弹窗、语音交流、AI 思考、录音测试和后台标签页期间不出现投影；恢复后重新排程。窗口尺寸改变时先收回，再按新边界出游，避开右下角入口和手机底部导航。面板可“关闭投影”或点击“看看投影”立即预览；开关为本次登录会话设置。系统启用“减少动态效果”、切到后台或退出登录时直接清理切换，不播放特效；退出减少动态模式后恢复待机计时。

点击小栖可打开快捷面板，进入聊天、设备和成员页面、打开偏好，或直接触发常用设备/场景操作；实际执行仍经过当前账号已有的权限校验。

账号、偏好、设备、家庭成员、聊天记录和声纹特征均由 Node 服务端保存到项目的 Git 忽略目录 `data/`，不会以浏览器存储作为正常持久化路径。聊天记录按登录账号隔离，只保留最近 200 条消息；可在聊天面板点击“清空对话”删除当前账号的服务器记录。删除成员时，会一并删除其账号、声纹和聊天历史。请妥善保护服务器目录及其备份；声纹文件使用受限文件权限保存，但当前未加密。

## 2. 在当前电脑上启用本地 AI

安装并启动 [Ollama](https://ollama.com/)，下载一个支持 JSON 输出的模型，例如：

```bash
ollama pull qwen3:4b
```

复制示例配置并启动：

```bash
cp .env.example .env
```

保持 `.env` 中 `OLLAMA_URL=http://127.0.0.1:11434` 和 `OLLAMA_MODEL=qwen3:4b`，再运行 `npm start`。启动后页面会显示 AI 模型状态。Ollama 不可用或返回格式错误时，指令会明确报错，不会假装设备已经执行。

文字指令由本机服务转发给本机 Ollama。手机端作为状态面板和远程控制器，不使用手机麦克风；家庭语音原型在家中电脑浏览器进行按键对话。

## 3. 家庭成员与语音功能

在“家庭成员”区域添加成员、填写关系，并可关联本项目中的智能家居设备；成员档案保存在被 Git 忽略的 `data/members.json`。终端关联则通过成员账号登录后选择“在此终端保持登录”完成，管理员可集中撤销。删除已关联的智能家居设备前，需要先在成员配置中解除关联。

当前语音功能是供家庭电脑测试的浏览器原型，尚未接入常驻麦克风阵列、唤醒词或 Home Assistant Voice 硬件。页面里有两种独立的语音功能：

- 家庭电脑聊天输入框的麦克风使用浏览器 Web Speech API 做**按键语音转文字**，助手回复会尝试通过电脑默认扬声器播报；不是始终监听。识别音频是否发送给浏览器厂商的服务取决于浏览器实现。手机布局会隐藏麦克风和声纹录入控件，只保留文字聊天和设备控制。
- 电脑端可点击右下角“小栖”面板里的麦克风与它进行一轮语音交流，回复通过浏览器语音合成播报；待机投影会在交流期间收回。语音识别仍由浏览器提供，可能使用浏览器厂商的服务，不是本地离线识别。手机端沿用仅文字聊天和远程控制的设计。
- “识别说话人（实验）”是声纹相似度测试。成员需先同意录入，并对提示短句录制 3 段样本；浏览器在本地提取特征向量并发送到家庭服务端，服务端将向量保存在 `data/voiceprints.json`，不保存或上传原始录音。旧版本保存在浏览器中的样本会在登录后征求确认，再迁移至服务端并删除浏览器副本。声纹数据属于敏感信息；该实验算法可能误识或漏识，不用于账号登录、个性化权限、门锁、安防或任何身份认证。

小栖支持按账号换肤：可上传不超过 5 MB 的透明 PNG、JPEG、WebP 或 GIF 图片（GIF 可动图），保存在服务器 `data/pet-skins/` 中，并可恢复默认形象。请仅使用你有权使用的素材。自定义图片保留原始画面/动图，不会被强行拆成手臂、口型等图层；角色状态提示与快捷面板照常工作。当前支持通用图片文件，不会解析其他桌宠专有的皮肤包或精灵图格式；如需兼容某款桌宠，需要针对它的文件格式另行实现导入器。

角色回归测试：运行 `npm test`，使用 Node 内置测试运行器检查 20 秒待机阈值、活动收回、多视角朝向、曲线转弯与入口避让、飞行帧清理、固定入口、预览/关闭、状态优先级、输入停止、后台/注销、减少动态效果与屏幕边界，无需安装测试依赖。

聊天内容会保存至 `data/chat-history.json`，按账号隔离，最多保留最近 200 条；清空对话会删除当前登录账号的服务器记录。删除家庭成员会级联删除该成员账号的聊天记录和声纹档案。以上数据文件不会提交到 Git；请自行保护服务器磁盘与备份权限。声纹文件权限受限，但数据文件当前未加密。

录入需要浏览器麦克风权限，并在 localhost 或 HTTPS 页面运行。后续接入家用音响/麦克风阵列时，应由家庭主机上的语音服务负责采集和播报，手机仍只通过网络查看状态和控制设备。

## 4. 手机访问

### 全屏运行

电脑或支持 Fullscreen API 的浏览器登录后，点击页面右上角的全屏图标；按 `Esc` 可退出。iPhone/iPad 的 Safari 不支持网页全屏按钮：请用 Safari 打开服务地址，点“分享”→“添加到主屏幕”，再从主屏幕图标启动。项目已配置独立窗口模式，启动后不会显示 Safari 地址栏和底部工具栏（系统状态栏仍可能显示）。页面需要连接家庭服务器才能使用，不支持离线控制。

### 同一 Wi-Fi 的临时测试

在 `.env` 中设置：

```dotenv
HOST=0.0.0.0
ADMIN_USERNAME=admin
ADMIN_PASSWORD=换成至少 10 位的随机密码
```

首次远程启动需要设置 `ADMIN_PASSWORD`（兼容使用 `APP_PASSWORD`）；账号初始化后改由网页中的独立账号登录，不再使用浏览器 Basic Auth 弹窗。重启 `npm start`，终端会显示电脑的局域网地址。手机连同一个 Wi-Fi 后打开该地址并使用家庭账号登录；只有个人可信手机才勾选保持登录。只在可信的家庭网络中这样测试；普通 HTTP 不加密，不要在公共 Wi-Fi 上输入密码或使用。

### 外出远程访问

建议让电脑和手机加入同一个私人 VPN（例如 Tailscale），再用 HTTPS 反向代理访问本机 `127.0.0.1:3000`。可用 Tailscale Serve 在 tailnet 内发布本地服务：

```bash
tailscale serve --bg http://127.0.0.1:3000
```

按终端提示使用它提供的 HTTPS 地址；在手机浏览器登录同一 tailnet，再使用家庭账号登录。首次在远程主机初始化账号时，将 `ADMIN_PASSWORD` 放入 `.env`。请限制 tailnet 成员/ACL，只允许可信设备访问。

**不要**把 3000 端口直接做路由器端口转发，也不要把 Home Assistant 的访问令牌放进前端代码。若不需要远程访问，保持默认 `HOST=127.0.0.1`。

## 5. 接入真实设备（Home Assistant）

建议让 Home Assistant 作为设备接入层：它负责 Zigbee、Matter、Wi-Fi 等设备和自动化；本项目负责实验助手交互。先在 Home Assistant 中完成设备配对，再在用户个人资料中创建长期访问令牌。将下面配置填入 `.env`：

```dotenv
HA_URL=http://homeassistant.local:8123
HA_TOKEN=你的长期访问令牌
HA_ENTITIES_JSON={"living-light":"light.living_room","living-ac":"climate.living_room","living-curtain":"cover.living_room_curtain"}
```

`HA_ENTITIES_JSON` 的键使用本项目已有设备 ID，值使用 Home Assistant 中对应的 `entity_id`。可只映射已有的设备；未映射设备继续使用模拟状态。修改配置后重启服务，页面顶部显示 `hybrid` 或 `home-assistant` 模式。Home Assistant 不可达、令牌无效或实体不存在时，页面会显示操作错误。

也可以在设备列表点“添加设备”或卡片上的 `···` 来添加、编辑、删除设备。添加纯模拟设备不需要 Home Assistant；绑定真实设备时，先配置并重启以加载 `HA_URL`/`HA_TOKEN`，再在设备配置中填写该设备的 `entity_id`。设备类型使用页面提供的选项；房间可以选已有名称，也可以输入新房间名。

先在受信任的本机/局域网完成测试，再配置 VPN 远程访问。迁移到树莓派或常开小主机时，在同一台可信主机上运行 Node 服务，并通过环境变量或受限权限的 `.env` 提供配置；不要将 `.env` 纳入版本控制。

## 当前边界

- 这是可运行的实验控制台，不是已认证的产品级家庭网关。
- 本地模拟状态只保存在服务进程内；Home Assistant 是真实设备状态的来源。
- 家庭电脑上的语音测试依赖浏览器 Web Speech API 和 SpeechSynthesis；通常需要 HTTPS/安全上下文及麦克风授权，识别服务是否联网取决于浏览器。
- 普通远程访问应走 HTTPS 私人 VPN；不要开放未经认证的控制 API 到公网。
